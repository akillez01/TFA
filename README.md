# Tecnofonia Ancestral

Site institucional do coletivo Tecnofonia Ancestral, desenvolvido com React,
TypeScript, Vite e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

O projeto é publicado no **Cloudflare Pages** a partir da branch `main` do
repositório `akillez01/TFA`.

- Build: `npm run build:prod`
- Saída: `dist`
- Projeto Pages: `tfa`
- Site: `https://tecnofoniaancestral.com`

Consulte [DEPLOYMENT.md](DEPLOYMENT.md) para o procedimento completo de
publicação, configuração DNS, domínio personalizado e diagnóstico de erros.
